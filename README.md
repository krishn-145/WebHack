🚀 About

WebHack is a lightweight and colorful Bash-based HTML fetching tool.

Enter a publicly accessible website URL and WebHack fetches the HTML response and saves it automatically inside the "HTML" folder.

---

✨ Features

- 🌐 HTML website fetching
- ⚡ Fast and lightweight
- 🎨 Colorful terminal interface
- 🔴 Recording-style UI
- 📁 Automatic output folder
- 📄 Automatic ".html" file creation
- 🔄 Redirect support
- 📊 File size information
- 🧾 HTML line count
- 📱 Termux support
- 🐧 Linux support

---

📱 Termux Installation

pkg update -y
pkg install curl -y
pkg install git -y

Clone the repository:
```
git clone https://gitHub.com/krishn-145/WebHack.git
cd WebHack
chmod +x WebHack.sh
./WebHack.sh
```

Then enter the website URL:

➤ https://example.com

The HTML file will be saved automatically:

HTML/example.com.html
